## Interview Guide
- Startups → your projects are the interview, leetcode almost irrelevant
- Mid-level iOS → Neetcode up to Tier 1 + Heap + 1-D DP, maybe 60-80 problems solid (assuming shipped production apps)
- FAANG → full Neetcode 150 + hard variants + system design + behavioral, 200-300+ problems (assuming industry experience at scale)

## LeetCode
### FOR Mid-Level IOS INTERVIEWS:
Tier 1 — Table stakes, will appear:
Hash Map / Arrays
Trees / BFS / DFS
Binary Search
Sliding Window
Stack

Tier 2 — Likely appears at mid-level:
Two Pointers
Heap / Priority Queue
1-D DP

Tier 3 — Possible but less common:
Graphs
Fast & Slow Pointers
Backtracking
Tries


### FOR FAANG IOS INTERVIEWS:
Tier 1 — Every round, guaranteed:
Hash Map / Arrays
Trees / BFS / DFS
Binary Search
Sliding Window
Stack
Two Pointers
Graphs
1-D DP

Tier 2 — Very likely appears:
Heap / Priority Queue
Backtracking
2-D DP
Tries
Fast & Slow Pointers
Intervals
Greedy

Tier 3 — Senior/Staff level:
Advanced Graphs (Dijkstra, Topological Sort, Union Find)
Bit Manipulation
Math & Geometry
2-D DP complex variants
